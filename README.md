# garmintides-data

Tidal harmonic constituents for the [Ventura Tides](https://github.com/freethebikes/GarminTides) Garmin watch face, served via GitHub Pages.

Each `tides/<id>.json` holds the 8 principal constituents (M2 S2 N2 K2 K1 O1 P1 Q1) for on-device offline tide prediction. U.S. cities: NOAA. Rest: EOT20 (CC BY 4.0).
